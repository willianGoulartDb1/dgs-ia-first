### 4️⃣ Exercício 1.2 — Plano de Habilitação e Documentação
**Timing:** Semana 2-4, durante desenvolvimento até D+30  
**Duração Estimada:** 12 horas distribuídas em 2-3 semanas

**Contém:**
- Análise de audiência
  - Perfil dos 45 atendentes
  - Audiências secundárias (supervisor, gerente de documentação, suporte)
  
- Plano em 3 fases
  - **Fase 1 (Pré-Lançamento D-7 a D-0):**
    - Preparação técnica (checklist de validação)
    - Materiais de treinamento (vídeo 3-5 min, guia rápido, FAQ, slides)
    - Sessão de treinamento ao vivo obrigatória (30 min por turno)
    
  - **Fase 2 (Lançamento D-0):**
    - E-mail de anúncio
    - Pinned message Teams
    - Suporte reativo (< 2h SLA)
    
  - **Fase 3 (Pós-Lançamento D+1 a D+30):**
    - Coleta de feedback estruturada (inline, survey, focus group)
    - Métricas de adoção (dashboard diário)
    - Iterações rápidas (ciclo de 3-5 dias)

- Templates prontos
  - E-mail de anúncio
  - Guia rápido (1 página laminável)
  - FAQ (1 página)
  - Dashboard de adoção

- Exemplo de roteiro de um atendente (Dia 1)

**Output:**
- 80%+ de atendentes completam treinamento ✅
- Nenhum atendente relata "não sabia como usar" ✅
- Dashboard mostra crescimento dia-a-dia ✅

### 5️⃣ Exercício 1.3 — Estratégia de Feedback e Iteração Rápida
**Timing:** Contínuo a partir de D+0  
**Duração Estimada:** ~2h/semana contínuamente

**Contém:**
- Framework de feedback em 3 níveis
  - **Operacional (diário):** Thumbs up/down, tickets suporte, escaladas QA
  - **Estruturado (semanal):** NPS, surveys, focus groups
  - **Diagnóstico (mensal):** Análise de queries erradas, abandono, cobertura

- Ciclos de iteração
  - **1 Semana (Rapid Fix):** Problema detectado → investigação (< 2h) → fix (< 24h) → teste → deploy → monitoramento
  - **1 Mês (Strategic Review):** Análise diagnóstica → review com sponsor → decisões para próximo mês

- Guia de ação por cenário
  - Se error rate > 10% em uma categoria (problema agudo)
  - Se adoção < 50% em D+7 (problema crítico)
  - Se novo caso de uso não suportado (oportunidade)

- Exemplo real: Semanas 1-4 de feedback em ação
  - Semana 1: FRETE com 14% error → fix em 24h → error cai para 6%
  - Semana 2: Focus group pede feature X → adiciona a backlog V1.1
  - Semana 3: DEVOLUÇÃO com 8% error → fix com 48h → error cai para 4%
  - Semana 4: NPS 7.0/10, adoção 93%, review estratégico com sponsor

- Dashboard de saúde em tempo real (exemplo)
- Template de relatório semanal (exemplo completo)
- Métricas de sucesso do feedback loop

**Output:**
- Em D+7: Demonstrar "aqui está o que aprendemos, aqui está o que mudamos" ✅
- Produto melhora visivelmente cada semana ✅
- NPS cresce de semana 1 para semana 4 ✅
